## 假設與理據

問題：單一 1H K 線跌幅 ≥1.5% 之後，3 小時內價格相對急跌低點回吐多少比例、方向如何？
理據來自 Scout 2026-11-14 提案：2026-11-13 夜 03:00 UTC 急跌（BTC −1.84%、ETH −2.80%）後
06:00 UTC 全數反彈為最佳小時（BTC +1.36%、ETH +1.44%），單夜即見急跌後數小時內的部分回吐；
若急跌後回吐比例系統性穩定，則是盤中小時結構的事實。Q10 與 Q9（小時波動的日內時鐘結構）互補，
條件變數為單小時急跌事件而非時鐘小時；與 Q5／Q7／Q8（日級波動條件）互補，條件變數為小時級急跌。

## 結果表

### 主表：急跌後 3 小時回吐（2,915 筆事件，平均跌幅 2.31%、中位 2.00%）

| 指標 | 數值 |
|---|---|
| 事件數 n | 2,915 |
| 平均跌幅／中位跌幅 | 2.31%／2.00% |
| R1 均值（+1h 回吐比） | 0.015 |
| R2 均值（+2h 回吐比） | 0.021 |
| **R3 均值／中位數（+3h 回吐比）** | **0.041／0.080** |
| Rmax 均值／中位數（窗口內最佳） | 0.350／0.301 |
| R3＞0（任何反彈） | 54.8% |
| R3≥0.5（回吐一半） | 28.2% |
| R3≥1.0（全數回吐） | 12.7% |
| R3＜0（繼續下跌） | 45.0% |
| 3h 前向報酬均值／中位數 | +0.10%／+0.18% |
| 3h 前向報酬為正占比 | 54.8% |

解讀：

1. **典型急跌後 3 小時只回吐約 8%（中位數），不是「回吐一半」。**
   R3 均值 0.041、中位數 0.080；回吐一半者僅 28.2%、全數回吐僅 12.7%，
   而 45.0% 的事件在 +3h 收盤時比急跌低點更低——急跌後繼續跌幾乎與反彈一樣常見。
   Rmax 均值 0.35 看似較高，但那是「三根取最大」的構造性偏高（取最大必 ≥ 各時點），
   且仍以收盤價計、未計手續費；把它讀成「平均回吐 35%」是錯的。
2. **前向報酬的 tilt 極小，約等於一趟手續費。**
   事件後 3h 前向報酬均值 +0.10%、中位 +0.18%，對照無條件全部小時的均值 −0.01%、
   中位 0.00%、為正占比 49.9%——急跌組僅比無條件高約 5 個百分點的為正率與 +0.11pp 的均值。
   以 Desk 手續費 0.05%/邊計，一買一賣成本 0.10%，均值報酬恰好被成本吃光（未計價差與滑價）。
   中位數 +0.18% 扣成本剩 +0.08%，且那是「在 +3h 收盤精準出場」的事後量測，不是可執行的交易規則。
3. **回吐路徑幾乎是平的。** R1 0.015 → R2 0.021 → R3 0.041：三小時內沒有「越晚回吐越多」的加速，
   +1h 時平均幾乎沒動，+3h 也只回吐 4%。所謂急跌後回吐，量級上就是不存在的現象。

### 劑量反應：跌越深，回吐比例越低——沒有「跌深反彈大」

四檔的 R3 均值在 −0.014～0.069 之間無單調趨勢；最深跌檔（≤−3.0%）回吐一半者僅 19.8%、
全數回吐僅 6.7%，為四檔最低——**跌越深，回吐比例越低**，與「超賣反彈」的直覺相反。
前向報酬均值隨跌幅略升（+0.10%→+0.24%）是分母效應：同樣的絕對反彈除以更大的跌幅，
R3 不升反降，兩者並不矛盾；且 +0.24% 仍約等於兩趟手續費，扣成本後無實質邊際。

### 輕跌安慰劑：小跌比大跌更容易「回吐一半」——是分母 artifact，不是訊號

輕跌組的 R3≥0.5（34.0%）與 R3≥1.0（20.1%）反而高於急跌組，但其 R3 均值更低（0.012）、
前向報酬均值僅 +0.01%——**小跌的分母小，同樣的雜訊波動就更容易跨過「一半／全數」的門檻**。
跨跌幅比較 R3 的門檻占比是分母 artifact，不得當作「輕跌反彈更強」的證據；
唯一可比的是前向報酬：急跌組 +0.10% vs 輕跌組 +0.01% vs 無條件 −0.01%，差距僅約 0.1pp。

## 對照

- **本項不是策略，不與冠軍 30/120 比績效。** 冠軍（BTC 4H 全歷史 +1365%／Sharpe 1.50／
  maxDD −17.1%／373 筆，DESK.md 基準）是方向性趨勢系統；Q10 是急跌事件的描述統計，
  無部位、無損益、無進出場規則，硬把描述統計包裝成策略對照表是類別錯誤。
- 與 Q3／Q9 的關係：Q3 已證明 30/120 交易的進場時段無可交易效應；
  Q9 證明小時波動本身有日內時鐘結構（開盤小時偏高）。Q10 補上第三塊拼圖：
  波動在特定小時偏高、急跌事件確實存在，但**急跌後 3 小時的價格並不系統性回吐**——
  波動結構存在，方向結構不存在。三者合起來的意思是：小時級的「動」是事實，「跌了會彈回來」不是。
- 若問「Q10 能否變成逢低買進策略」：本項不回答——Q10 原文只做到描述統計。
  僅記錄邊界：(a) 3h 前向報酬均值 +0.10% 恰等於一趟手續費（0.05%×2），扣成本後為零，
  且非重疊子集僅 +0.05%，連成本都不夠；(b) 45% 事件繼續跌，任何無停損的逢低買進
  會在近半數事件上擴大虧損；(c) 觸發夜本身就是反例對——11-13 夜 BTC／ETH 只回吐 8%，
  11-14 夜 14:00 事件全數繼續跌。本項到此為止，不延伸、不建 paper bot。

## verdict

**Q10 完成，結論是否定：單小時急跌後 3 小時沒有系統性的回吐。**
典型事件只回吐跌幅的約 8%（中位數 R3＝0.080），回吐一半者僅 28.2%、全數回吐僅 12.7%，
45.0% 繼續下跌；3h 前向報酬均值 +0.10% 恰等於一趟手續費，非重疊子集僅 +0.05%，
劑量反應無單調趨勢（跌越深、回吐一半的比例越低：≤−3.0% 檔僅 19.8%／6.7%），
BTC／ETH 兩大幣的 R3 均值甚至為負。觸發夜的「06:00 全數反彈」經逐根核對是真實的單根反彈，
但它發生在又跌兩根之後，BTC／ETH 的 3 小時回吐只有約 8%——提案的理據方向正確、量級被高估，
且隔夜 11-14 的 14:00 事件全數走反向。**不建策略、不標 SURVIVOR、不進 Builder，Q10 線關閉。**
後續若有人想拿「急跌後會彈」做文章，必須先回答本報告的核心反例：
中位回吐只有 8%、45% 繼續跌、均值報酬等於手續費——「跌了」不等於「會彈回來」。

## WHY THIS COULD FAIL

- **回吐以收盤價量測，盤中高點未計入。** Rmax 以三根收盤的最大值計，是盤中回吐的下界；
  若改用 1H 高點（high）計算，窗口內最大回吐會更高。但主結論依賴的是 +3h 收盤的 R3
  （中位 0.08）與前向報酬（+0.10%），這兩個量不受 high 口徑影響；high 口徑只會抬高 Rmax，
  不會改變「3 小時收盤沒回吐多少」的事實。盤中高點的回吐需要逐 tick 執行假設才能交易，
  不在本項範圍內。
- **樣本期只有 2025-01～2026-11，未覆蓋熊市或流動性枯竭期。**
  兩年皆屬同一輪市場結構；2026 年事件數（931）不到 2025 年（1,984）一半，
  反映 2026 年整體低波動 regime。結論外推到其他 regime 須謹慎——但兩年 R3 中位數
  幾乎相同（0.079／0.082），方向穩定性高於量級。
- **事件叢聚，獨立樣本小於事件數。** 急跌常連續出現（同一波下跌多根達標），
  2,915 筆事件的有效獨立樣本遠小於此數；非重疊子集（2,341 筆）結論更弱（R3 均值 0.021），
  顯示全部事件的微弱 tilt 有一部分是重複取樣造成——若計入叢聚，證據比帳面更弱，不是更強。
- **門檻 −1.5% 是提案給定，未做敏感性掃描。** 劑量反應四檔已覆蓋 −1.5%～−3% 以上的範圍
